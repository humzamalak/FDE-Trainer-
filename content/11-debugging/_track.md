# 3d. Reading and debugging unfamiliar code
<!-- order: 3.8 -->
<!-- skill: coding -->
<!-- weeks: 13-14 -->

On day one at a customer you open a codebase you have never seen, and something is broken. This track teaches a method for reading code fast and finding bugs with evidence instead of guessing. Each exercise is a small "customer program" with a real bug and a bug report. Weeks 13–14. Practise with the **Debugging round** mock interview.
